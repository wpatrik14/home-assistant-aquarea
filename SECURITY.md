# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/wpatrik14/home-assistant-aquarea/security) of this
repository, choose **Report a vulnerability** and describe the problem (what you
found, how to reproduce it, which version). This creates a private security
advisory that only the maintainer can see.

Never include your Panasonic password or tokens in a report; redact them from
logs and diagnostics first.

You can expect an answer within a few days. A confirmed problem is fixed in a
new release and credited in the advisory unless you prefer otherwise.

Problems in the Panasonic cloud service itself, or in Home Assistant, should be
reported to Panasonic and to Home Assistant respectively. Problems in the
[aioaquarea-ng](https://github.com/wpatrik14/aioaquarea) library can be
reported the same way in that repository.
